# 🍽️ Dinner Ideas

**Dinner Ideas** is a modern AI-powered web application that helps users discover meal ideas based on the ingredients they already have.

Users can enter available ingredients, optionally specify a cuisine and dietary preference, and receive personalized meal suggestions generated by **Google Gemini AI**.

## ✨ Features

* 🤖 **AI-powered recipe generation** — generate personalized meal ideas using Google Gemini AI.
* 🥕 **Ingredient-based recommendations** — enter the ingredients you already have and get suitable meal suggestions.
* 🌎 **Cuisine selection** — optionally specify a preferred cuisine.
* 🥗 **Dietary preferences** — optionally specify a diet.
* 🍽️ **Three recipe suggestions** — receive three different meal ideas based on the request.
* 🔄 **Generate new ideas** — generate another set of recipes using the same ingredients and preferences.
* ❤️ **Favorites** — save recipes you like and access them later.
* 🌐 **Internationalization** — support for multiple languages.
* 🌓 **Theme switching** — switch between light and dark themes.
* 💻 **System theme detection** — automatically use the user's system preference as the default theme.
* 📱 **Responsive design** — optimized for different screen sizes.

## 🧠 How It Works

1. Enter the ingredients you currently have.
2. Optionally select a cuisine.
3. Optionally specify a dietary preference.
4. Click **Generate Recipes**.
5. The request is sent to the application's server-side API.
6. The API validates the request and communicates with Google Gemini.
7. Gemini generates three recipe suggestions.
8. The recipes are displayed to the user.
9. Users can save recipes to their favorites or generate a new set of ideas.

The **Generate New Ideas** functionality allows users to receive different recipes while keeping the same ingredients, cuisine and dietary preferences.

## 🔐 Server-Side API

The application uses a Next.js API route as a server-side layer between the client and Google Gemini.

```text
Client
  ↓
Next.js API Route
  ↓
Request validation
  ↓
Google Gemini API
  ↓
Generated recipes
  ↓
Client
```

The main API endpoint is:

```text
/api/ideas
```

The API route is implemented using Next.js server-side functionality:

```text
app/api/ideas/route.ts
```

This approach keeps the Gemini API key on the server instead of exposing it to the client.

## 🌐 Internationalization

The application supports multiple languages through an internationalization system.

Localized routes are organized using:

```text
app/[locale]/
```

Translation files are stored in:

```text
messages/
```

Internationalization is currently being finalized and improved.

## 🎨 Themes

Dinner Ideas supports both light and dark themes.

Users can manually switch between:

* ☀️ Light theme
* 🌙 Dark theme

The application also detects the user's system preference and uses it as the default theme when the application is opened.

## ❤️ Favorites

Users can save recipes they like to their favorites.

This allows them to keep interesting recipes and access them later without generating them again.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/lilp3ka/dinner-ideas.git
```

Navigate to the project directory:

```bash
cd dinner-ideas
```

Install dependencies:

```bash
npm install
```

### Environment Variables

Create a `.env.local` file in the root of the project:

```env
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your Google Gemini API key.

> ⚠️ Never commit your `.env.local` file or expose your Gemini API key publicly.

### Run the Development Server

```bash
npm run dev
```

Open http://localhost:3000 with your browser.
